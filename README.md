## General info

[Computer Store Tycoon Game](https://www.roblox.com/games/5380202554) is a business-simulation game on the Roblox platform in which players build, customize and manage their own retail computer store — from laying out shelves and displays to hiring staff and growing the business over time.

<p align="center">
  <a href="https://www.roblox.com/games/5380202554">
    <img src="photos/icon.png" alt="Game icon" width="25%">
  </a>
</p>

**Core features:**
- Placement & customization system for shelves, displays, signs and lighting (colors, materials, positioning)
- NPC customers, cashiers and storemen, each driven by their own behavior scripts
- Store rating, achievement and daily-reward systems
- Plot expansion, parking and storefront upgrades
- In-game economy with Robux-based purchases (currency packs, boosts, expansions)
- Multiple save slots backed by automatic, retry-safe data persistence

### Important note

This repository is provided for reference only and will not allow you to fully recreate the game. It excludes several third-party modules, and it is missing most models, folders, events, attributes and other structural pieces of the full Roblox Studio workspace.

## Used modules

The game contains some models/modules based on creations of other people:

- Placement module based on zblox164's "PlacementModuleV3"
- Color picker based on Stonetr03 Studios's "Color Picker"
- Feedback system based on MrSprinkleToes's "Feedback System"
- Daily reward system based on Sub2HTR (HowToRoblox)'s "Daily Rewards"

## Notes

This was my first major project. I started it at 15 years old and spent three years building it solo, end to end — programming, 3D modeling, animation, sound design and UI. As a first project, it inevitably contains rough code, inconsistent patterns and suboptimal design decisions; the scope had grown too large to refactor thoroughly before I needed to shift my focus to university preparation and final exams. The game is no longer actively maintained, but it remains a meaningful milestone in my early development as a self-taught programmer and game developer. Thanks for taking the time to look around.
